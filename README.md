# Uquis Dauntless Minecraft Mod

Uquis Dauntless is a Fabric Minecraft mod for heavy PvP and challenging survival gameplay, with harsh rules that remove water based escape and resource mechanics. The mod blocks water buckets and fishing rods, removes nearby water around players, and displays the active rules when players join.

## Install

1. Install Java 25 or newer.
2. Install Fabric Loader 0.20.1 or newer for Minecraft 26.3.
3. Install Fabric API.
4. Build or obtain the `bloodtide-1.0.0.jar` file.
5. Place the JAR file in the `mods` folder of the Minecraft server or client.
6. Start Minecraft with the Fabric profile.

Use a fresh world for the intended experience because nearby water is removed continuously around players.

## Use

1. Start the Fabric server or client with the mod installed.
2. Join the world.
3. Read the rules message displayed when you join.
4. Play with water buckets and fishing rods disabled.
5. Stay aware of nearby water, which is continuously removed in a small area around each player.

The mod is configured for Minecraft 26.3 and requires Fabric API.
